# LessCode

Review a committed JavaScript or TypeScript change and receive a cited note plus a gate-accepted patch when one survives. The source checkout stays unchanged. A note-only result is a successful review.

## Start here

1. [Install](install.md): build from source or install a local tarball; this package is not published to npm.
2. [Configure a provider](providers.md): supply operator credentials and select both roles explicitly.
3. [Run a review](run.md): choose the committed head, comparison base, scope and execution mode.
4. [Interpret the result](run.md#interpret-the-record): distinguish patch acceptance, factual verification and unverified advice.
